GitHub 文件与 API 加速

GitHub，加速。

简单、快速的 GitHub 边缘代理。 文件、Release、源码归档与 API，通过代理节点访问。

支持 http://、https://，或直接输入 github.com/... 地址

示例

点击即可使用
Release github.com/zFlqwovo/gh-proxy/releases/latest ↗
Archive github.com/zFlqwovo/gh-proxy/archive/refs/heads/main.zip ↗
Blob github.com/zFlqwovo/gh-proxy/blob/main/snippets.js ↗
Raw raw.githubusercontent.com/zFlqwovo/gh-proxy/main/README.md ↗
Gist gist.githubusercontent.com/zFlqwovo/example/raw/example.py ↗
API api.github.com/repos/zFlqwovo/gh-proxy ↗

怎么使用

  • 复制一个 GitHub 文件或 API 地址
  • 粘贴到上方输入框
  • 点击「开始加速」即可访问

支持范围

GitHub Releases、Archive、Blob、Raw、 Gist、API 以及部分 GitHub 资源。 具体支持范围取决于代理服务配置。

本服务主要用于改善 GitHub 资源访问体验。 请合理使用，不要用于违反 GitHub 或相关服务条款的用途。
